GitHub Repository README Documentation

⚠️ গিটহবে এটি সরাসরি ওপেন না হওয়ার কারণ:

SafeGuard কোনো সাধারণ ওয়েবসাইট বা HTML প্রজেক্ট নয়। এটি একটি পূর্ণাঙ্গ Native Android Application (Android App) যা Kotlin, Android VpnService এবং Jetpack Compose দিয়ে তৈরি। গিটহাব পেজেস (GitHub Pages) বা ওয়েব হোস্টিং সার্ভিসগুলো সাধারণত ব্রাউজারে রান করানোর জন্য index.html ফাইল খোঁজে। কিন্তু অ্যান্ড্রয়েড অ্যাপ ব্রাউজারে নয়, সরাসরি অ্যান্ড্রয়েড ফোন বা Android Studio-তে চালাতে হয়।

📱 কীভাবে অ্যাপটি চালু বা ব্যবহার করবেন?

  1. ১. Android Studio দিয়ে ওপেন করুন:
    আপনার কম্পিউটারে Android Studio ওপেন করে File → Open সিলেক্ট করুন এবং এই প্রজেক্টের রুট ফোল্ডারটি বেছে নিন। Gradle স্বয়ংক্রিয়ভাবে সমস্ত ডিপেনডেন্সি সিঙ্ক করবে।
  2. ২. এমুলেটর বা সরাসরি মোবাইলে রান করুন:
    আপনার অ্যান্ড্রয়েড ফোন USB কেবল দিয়ে কানেক্ট করুন অথবা Android Studio-র ভার্চুয়াল এমুলেটর সিলেক্ট করে Run (Shift + F10) বাটনে ক্লিক করুন।
  3. ৩. সরাসরি APK বিল্ড করতে চাইলে (Terminal / CMD):
    # Debug APK তৈরি করার কমান্ড: ./gradlew assembleDebug # বিল্ড হওয়া APK এই লোকেশনে পাওয়া যাবে: app/build/outputs/apk/debug/app-debug.apk
    এই APK ফাইলটি আপনার ফোনে পাঠিয়ে সরাসরি ইনস্টল করে ব্যবহার করতে পারবেন।
